CollabX — A full-stack collaboration platform where users can create, discover, and join team projects. Built with Node.js, Express, MongoDB, and Socket.io for real-time messaging. Features include user authentication, project creation with categories (hackathon, startup, research), skill-based team matching, invite codes, application workflows, and a real-time chat system. Supports both MongoDB Atlas and an in-memory fallback for local development.
